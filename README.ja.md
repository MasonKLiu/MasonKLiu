* 💻 **基幹システムのモダナイゼーション：** レガシーな基幹システム（MES・ERP・WMS・eRMA）を、クリーンアーキテクチャに基づく Go バックエンドと Next.js / Vue / GraphQL フロントエンドへ刷新・統合しています。
* 🤖 **マルチエージェント・ローカルAI開発：** マルチエージェント協調基盤（`agent-team`）や MCP サーバー、Obsidian・SQLite・ベクトル検索を組み合わせたローカルナレッジグラフを構築しています。
* 🎯 **開発ポリシー：** 型安全な API 設計、高スループットなデータ処理基盤、保守性の高いレイヤード設計と安定した本番環境運用を重視しています。
* 🌏 **言語スキル：** 繁体字中国語（ネイティブ） · 英語（ビジネスレベル） · 日本語（学習中・JLPT N1 目標）
